NOVAHAUL WEBSITE STARTER

Includes a mobile-friendly storefront, sample product cards, category filters and a front-end shopping bag.

Important:
- This is a visual starter/preview, not a live e-commerce system.
- Sample product prices are illustrative and must be confirmed.
- Replace hello@novahaul.example with an email address you control.
- Checkout is intentionally not connected. No Paystack payments, secure order database or private admin dashboard are included yet.
- Never put Paystack secret keys in front-end code.
- Only use product photos you have permission to use.

Files: index.html, styles.css, app.js.
