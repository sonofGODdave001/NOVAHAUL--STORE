NOVAHAUL COMPLETE STOREFRONT FRONT-END STARTER

Included:
- index.html — home page
- products.html — product collection with search/category filter
- cart.html — shopping bag, quantities, removal and subtotal
- checkout.html — delivery details and Pay on Delivery option (demo only)
- admin.html — add/edit/delete products and prices in this browser (demo only)
- styles.css and app.js — styling and functionality

IMPORTANT:
This is a FRONT-END STARTER, not a production-ready store.
The checkout does not submit orders. Paystack is not connected. Pay on Delivery is not connected to a courier/order workflow. The admin page is NOT private or secure: anyone can open it, and product edits are saved only in that browser's local storage, not for all visitors. Sample prices are illustrative; confirm supplier prices, stock and delivery charges.

Before real sales, add a backend/database, secure admin authentication and role permissions, server-side product catalog, secure order storage, delivery workflow, and server-side Paystack initialization/payment verification/webhook. Never put secret API keys in HTML or JavaScript. Add accurate contact, shipping, returns/refunds, privacy and terms pages before launch.

Upload all files directly into the root of the GitHub repository (same folder as index.html) and commit. Then use Settings > Pages > Deploy from a branch > main > /(root).
